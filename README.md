# Гофермарт — накопительная система лояльности

## Назначение

Система лояльности для интернет-магазина «Гофермарт». Пользователи регистрируются, загружают номера заказов, получают начисления баллов (1 балл = 1 рубль) и могут списывать их для оплаты следующих заказов. Взаимодействие с внешним сервисом расчёта начислений.

---

## Архитектура и ключевые решения

- **Два независимых сервиса**:
  - **Gophermart** — основное HTTP API для пользователей (регистрация, загрузка заказов, баланс, списание)
  - **Accrual System** — сервис расчёта начислений (приём заказов, регистрация механик вознаграждений, расчёт баллов)
- **PostgreSQL** — единое хранилище для обоих сервисов
- **JWT-аутентификация** — авторизация пользователей через токен в заголовке `Authorization`
- **Асинхронная обработка заказов** — заказы принимаются и обрабатываются в фоне через воркеры, клиент получает статус через API
- **Алгоритм Луна** — валидация номера заказа перед приёмом
- **Гибкая конфигурация** — адреса запуска, подключение к БД и адрес accrual-системы задаются через env или флаги

---

## Результат

- Пользователи могут регистрироваться, загружать заказы и отслеживать статус начисления баллов.
- Автоматический расчёт вознаграждений через внешнюю систему с поддержкой процентных и точных механик.
- Возможность списания баллов в счёт оплаты новых заказов.
